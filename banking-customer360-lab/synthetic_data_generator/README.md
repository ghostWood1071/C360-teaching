# Synthetic Data Generator

- `configs/`: hồ sơ small, standard, stress.
- `schemas/`: DDL nguồn và schema Parquet.
- `src/`: logic sinh, scenario, validation, profiling, writer.
- `scripts/`: CLI generate, validate, profile.
- `tests/`: integration tests.
